# Individual Information Display Program

## Description
A simple Java program that demonstrates basic programming concepts by declaring variables and printing personal information for a fictional person to the console.

## Programming Concepts Demonstrated
- Variable declaration and assignment
- String data types
- Console output using `System.out.println()`
- String concatenation
- Basic Java program structure

## Requirements
- Java Development Kit (JDK) 10 or higher (for `var` keyword support)

## How to Run
1. Navigate to the project directory
2. Compile the program:
   ```bash
   javac invidinfo/IndividualInfo.java
   ```
3. Run the program:
   ```bash
   java invidinfo.IndividualInfo
   ```

## Expected Output
```
First name: Sherlok
Last name: Homes
Street address: 221 B Baker Street
City: Loudon
Zip code: VA
```
